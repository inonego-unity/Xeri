# 소유권과 수명

## 배경

Xeri의 여러 Runtime 기능은 등록, 로드, 표시, 재생처럼 명시적인 시작과 종료가 필요한 상태를 다룹니다. 이러한 상태는 생성만 하고 잊는 대신, 누가 소유하고 언제 종료하는지를 공개 계약으로 표현합니다.

## 핵심 모델

```text
획득 / 등록 / 시작
        ↓
Handle · Lease · Session
        ↓
소유자가 보관
        ↓
Dispose / Release / Close
```

모든 모듈이 같은 타입을 사용하는 것은 아니지만, 반환된 수명 객체를 실제 사용 범위의 소유자가 보관한다는 원칙은 공통입니다.

## 주요 형태

| 형태 | 의미 |
|---|---|
| `Lease` | 특정 요청 또는 외부 자원의 수명을 일회성으로 소유 |
| `Handle` | 등록, Layer, Modal, Overlay 등 명시적 획득 상태를 소유 |
| `Session` | 화면, 문서, 재생처럼 일정 기간 유지되는 작업 상태를 소유 |
## 규칙

- 획득한 객체의 종료 책임자를 호출 시점에 결정합니다.
- 부모 범위와 함께 끝나야 하는 수명은 가능한 경우 부모 Session 또는 소유 객체에 연결합니다.
- 종료 순서가 중요한 경우 소비자를 먼저 종료하고 기반 리소스를 나중에 종료합니다.
- 실제 계약이 재시도를 요구하지 않는 `Dispose` 실패를 임의의 복구 상태 머신으로 확장하지 않습니다.
- Addressables처럼 외부 release가 필요한 값은 값과 수명 책임을 분리하지 않습니다.
